# carcel.dev

## Requirements

- [Bun](https://bun.com/)
- [Task](https://taskfile.dev/)

## How to use it?

Run the application:
```shell
$ task run:dev
```

Then access it through [http://localhost:3000](http://localhost:3000).

The full list of actions can be accessed by running the following command in your usual terminal:
```shell
$ task
```
